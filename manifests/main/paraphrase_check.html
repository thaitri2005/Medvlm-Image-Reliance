How to judge

Read only the two questions. Don't think about the image or the model. When unsure, choose N.

Same meaning (Y)

  • Perception framing: “is X seen”, “is X visible”, “can X be seen to be enlarged”
  • Exact synonyms: clavicle / collarbone, encephalon / brain
  • Reordering with the same content

Could change the answer (N)

  • Fact turned into possibility: “Is the heart enlarged?” → “Can the heart be enlarged?”
  • Broader or narrower term: mass → lesion, organs → structures
  • Changed relation: “does A show B” → “is A associated with B”
  • Added or dropped scope: “bilaterally”, left / right, a modality
  • Antonyms or a different plane: coronal → transverse
  • Two questions in one, or malformed text

Keys: Y, N, ← →. Ratings save as you go.
